# 手势粒子创作工具

浏览器本地图片采样与粒子创作工具。PNG/JPG/SVG 通过浏览器 File API 载入，图像像素、alpha 通道、引导图和粒子均在本机浏览器内处理；项目没有图片上传接口或应用服务器。默认黑色画布，内置蓝金凤凰与白虎示例。

## 运行
摄像头权限需要安全上下文，请在项目目录启动本地静态服务器：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000`。图片创作、键盘鼠标控制和预设读写无需摄像头。点击“启用手势”后授权摄像头；手势识别在浏览器本地运行。首次启用时浏览器需要从 jsDelivr 获取 MediaPipe 运行库/ WASM，以及从 Google MediaPipe 模型库获取手部模型；摄像头帧和用户图片不会上传。

## 控制

- PNG/JPG/SVG：添加一张或多张；透明 PNG 按 alpha 采样。对无 alpha 的 JPG/SVG，按边缘背景色做基础抠除。
- 鼠标点击画布或空格：聚合/散开；左右方向键：切换示例与上传图片；H：隐藏/显示 UI。
- 捏合或握拳：聚合；张开手掌：散开；水平挥手：切换图片。
- 面板可调粒子数量、大小、颜色、原图颜色、散开范围、聚合速度、辉光、引导图透明度和缩放。
- “保存预设”导出 JSON；“读取预设”载入 JSON。预设只保存参数，不包含图片。
